# Tablero Supply Chain Don Maíz (versión web)

Copia pública del tablero que vive en Claude, para abrirlo en cualquier navegador sin iniciar sesión.

- `index.html`, `data/`, `fonts/`, `lib/`: la página publicada con GitHub Pages.
- `tools/build_web.py`: arma la página a partir del tablero de Claude (`tools/pagina_tablero.html`) y de los datos de cada módulo.
- Se actualiza sola de lunes a sábado con una tarea programada de Claude, después de las actualizaciones del día.

No edites `index.html` ni `data/` a mano: se reemplazan en cada actualización.
